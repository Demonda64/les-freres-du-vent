# LES FRERES DU VENT - CARTE GENERATIONNELLE

## Generation 1 - Les Fondateurs

```text
Zeke Kane <-> Silas "Red" Mox
|             |
|             -> developpe Crimson Cross
|
-> cree Les Freres du Vent

Rupture:
Zeke quitte tout -> famille
Red reste -> pouvoir
```

### Lecture

Zeke represente:
- choix
- fuite
- protection

Red represente:
- continuite
- pouvoir
- domination

Theme:
> On ne fuit jamais vraiment ce qu'on a cree.

## Generation 2 - Les Heritiers Brises

```text
Ghost <-> Scarlett
  |          |
  |          -> lien fort avec Zeke
  |
  -> eleve Ryder

Ryder Kane <-> Marcus Colton
   |              |
   |              -> meilleur ami
   |
   -> figure centrale / heritier actif

Boomer
|
-> oncle de Marcus
-> protege Marcus pendant Velvet au prix de Ryder

Point de rupture:
VELVET -> mort de Ryder
       -> exclusion puis silence de Ghost
       -> disparition de Scarlett
```

### Lecture

Ghost represente:
- silence
- tutelle ratee
- fidelite impossible

Scarlett represente:
- protection sans explication
- route alternative
- perte quasi maternelle de Ryder

Ryder represente:
- heritier actif
- pont entre les mondes
- mort qui remet tout en mouvement

Marcus represente:
- heritier emotionnel
- second permanent
- rivalite nee du manque

Boomer represente:
- protection fautive
- culpabilite
- sacrifice de Ryder par amour de Marcus

## Generation 3 - Les Heritiers Du Chaos

```text
Dagger / Silas Merel
|
|- fils de Zeke
|- porte le prenom de Mox
|- porte le nom Merel de sa mere
|- n'a pas vecu Gasthaven

Marcus
|
|- heritier emotionnel de Ryder
|- tue Boomer

Torch
|
-> rejete -> devient traitre

Razor
|
-> fils de Mox -> tue son pere

Grimm
|
-> dernier arbitre du systeme
```

### Lecture

Dagger represente:
- heritier inconscient
- conflit vivant
- choix possible

Marcus represente:
- rival
- parricide symbolique
- redemption possible

Torch represente:
- rejet
- besoin d'etre vu
- trahison

Razor represente:
- sang de Mox
- rupture du pere
- alliance inattendue

Grimm represente:
- jugement
- ordre froid
- survivance du systeme

## Boucle

```text
Zeke fuit -> Red construit
Ryder revient -> meurt
Dagger revient -> choisit
Nouveau monde
```

## Regle Writers Room

Chaque generation doit transmettre une dette a la suivante.

Chaque scene importante doit pouvoir se lire sur au moins un axe:
- fondateurs: Zeke / Red
- heritiers brises: Ryder / Ghost / Scarlett / Marcus / Boomer
- heritiers du chaos: Dagger / Marcus / Torch / Razor / Grimm

## Note Canon

Le lien Scarlett / Zeke est une fascination profonde et une marque ancienne, pas une obsession romantique simple.

La relation Scarlett / Ryder est quasi maternelle, sans ambiguite romantique.
